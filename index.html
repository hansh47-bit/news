ABOUT NEWSRANK DESKTOP

newsrank is a dedicated desktop application for our editorial operation. It transforms trending news into vertical videos and social posts, and publishes to TikTok only after an authorized editor explicitly approves the content within the desktop client.

  • Desktop client for owned-account publishing only (no web login required for public users)
  • Mandatory human review and approval before every social post
  • TikTok integration uses Content Posting API (Direct Post) for approved videos

서비스 소개

newsrank는 자사 뉴스·콘텐츠 운영을 위한 데스크톱 숏폼 퍼블리싱 프로그램입니다. 이슈를 세로형 영상과 카드로 만들고, 운영자가 승인한 결과물만 자사 틱톡·인스타·유튜브 계정에 게시합니다.

  • 불특정 크리에이터용 공개 웹 서비스가 아닌 사내 운영용 데스크톱 프로그램입니다
  • 게시 전 반드시 담당자 승인이 필요합니다
  • 틱톡 연동 시 Direct Post로 승인된 영상만 올립니다
